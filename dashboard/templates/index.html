Quick Setup Guide

  1. Set the Staff Role above — enter the Discord role ID that should have access to all tickets.
  2. Set the Log Channel — enter the Discord channel ID where transcripts will be saved.
  3. Click Save Configuration to apply.
  4. In your Discord server, run /ticket-panel to post the ticket creation panel.
  5. Users click Create Ticket → select type → fill in the form → a private channel is created.

💡 Tip: Enable Discord Developer Mode (User Settings → Advanced → Developer Mode) to easily copy role and channel IDs by right-clicking them.
